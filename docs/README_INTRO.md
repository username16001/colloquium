# Коллоквиум · Python

Приложение для устной подготовки к коллоквиуму по Python на основе 14 лекций. Отвечайте своими словами, сверяйтесь с объяснениями и возвращайтесь к вопросам, которые требуют повторения.

**[Открыть приложение →](https://username16001.github.io/colloquium/)**

## Возможности

- **Практика:** вопросы со скрытыми ответами и подробными объяснениями.
- **Голосовая подготовка:** запись речи, редактируемый текст и разбор нейросети после подключения сервера Groq.
- **Умная подготовка:** подбор вопросов с учётом ошибок и предыдущих повторений.
- **Лекции:** все вопросы каждой из 14 лекций, ответы и избранное в разделе «Прогресс».
- **Личный прогресс:** история ответов, освоение лекций и вопросы для повторения.
- **Избранное:** сохранение вопросов для возвращения к ним в разделе лекций.
- **Удобное оформление:** светлая, тёмная и системная темы, подсветка Python-кода, копирование кода и математические формулы.
- **Офлайн-доступ:** подготовка без интернета после загрузки ресурсов приложения.

## База вопросов

В приложении доступны **437 уникальных вопросов**:

- **137 исходных** из прошлого коллоквиума.
- **300 дополнительных**, составленных по материалам 14 лекций.

Происхождение обозначено метками **«Прошлый коллоквиум»** и **«По лекциям»**. Можно заниматься по всей базе или отдельно по исходным заданиям.

Вопросы охватывают теорию, понимание кода, глубокое понимание механизмов Python, алгоритмы, формулы, доказательства и нестандартные случаи. Для новых заданий приведены ответы, объяснения и ссылки на соответствующие материалы лекций.

[Посмотреть полный сборник вопросов](QUESTIONS.md)

## Как заниматься

- **Практика:** ответьте устно, откройте ответ и оцените себя.
- **Умная подготовка:** повторяйте вопросы, подобранные с учётом ошибок и истории занятий.

Выберите «Стандартный режим» на главной, ответьте устно и откройте эталон. Затем выберите «Ответил правильно» или «Ошибся / не смог ответить». В «Голосовом управлении» запишите ответ, исправьте расшифровку и отправьте на проверку: Groq выставит оценку, объяснит ошибки и при необходимости задаст уточняющий вопрос. Для проверки нужен подключённый сервер; [инструкция для владельца](VOICE_SETUP.md). Пауза и завершение доступны через меню «⋯».

## Прогресс

В разделе «Прогресс» можно посмотреть результаты по лекциям, историю занятий и вопросы, к которым пора вернуться. Последние 30 оценок показаны страницами по пять; полная история сохраняется для статистики и экспорта. Первые ответы и повторные попытки учитываются отдельно.

Незавершённая тренировка сохраняется — после возвращения можно продолжить с того же места.

Прогресс и диалоги сохраняются на вашем устройстве. В голосовом режиме текст ответа передаётся в Groq для проверки, а речь обрабатывается службой распознавания браузера. Для резервной копии или переноса прогресса в другой браузер используйте **экспорт и импорт JSON** в настройках. Автоматической синхронизации между устройствами нет.

## Установка и офлайн

Приложением можно пользоваться в обычной вкладке или установить его, чтобы запускать с отдельной иконки.

### iPhone — Safari

1. Откройте [приложение](https://username16001.github.io/colloquium/) в Safari.
2. Нажмите **«Поделиться»**. В зависимости от оформления Safari эта кнопка может находиться в меню страницы.
3. Выберите **«На экран “Домой”»**.
4. Если доступен переключатель **«Открыть как веб-приложение»**, включите его.
5. Нажмите **«Добавить»**.

Иконка появится на экране «Домой». Если нужного пункта нет в меню, найдите его через «Редактировать действия». [Инструкция Apple](https://support.apple.com/ru-ru/guide/iphone/iphea86e5236/ios).

### Mac — Safari

1. Откройте сайт в Safari.
2. Выберите **«Файл» → «Добавить в Dock»** или тот же пункт через кнопку «Поделиться».
3. Укажите название приложения и нажмите **«Добавить»**.

Приложение можно запускать из Dock или через Spotlight. Установка таким способом доступна в macOS Sonoma 14 и новее; в более старых версиях используйте вкладку браузера. [Инструкция Apple](https://support.apple.com/en-ie/104996).

### Android — Chrome

1. Откройте сайт в Chrome.
2. Нажмите меню **⋮ → «Установить и создать ярлык» → «Установить»**.
3. Подтвердите установку, следуя подсказкам браузера.

После установки запускайте приложение с появившейся иконки. [Инструкция Google](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ru).

### Windows — Chrome или Edge

Откройте сайт и воспользуйтесь значком установки в адресной строке, если он появился. Установку также можно найти в меню браузера:

- **Chrome:** **⋮ → «Транслировать, сохранить, поделиться» → «Установить страницу как приложение»**. [Инструкция Google](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DDesktop&hl=ru).
- **Edge:** **… → «Дополнительные инструменты» → «Приложения» → «Установить этот сайт как приложение»**. [Инструкция Microsoft](https://support.microsoft.com/en-us/edge/install-manage-or-uninstall-apps-in-microsoft-edge).

Подтвердите установку. Приложение будет открываться в отдельном окне.

### Подготовка без интернета

Для первого запуска нужно подключение к интернету: приложение сохраняет на устройстве базу вопросов, ответы, объяснения и остальные необходимые ресурсы.

1. Откройте приложение при подключённом интернете. Если установили его, запустите именно установленную иконку.
2. При первом сохранении ресурсов дождитесь сообщения **«Ресурсы сохранены для офлайн-подготовки»**.
3. Отключите интернет и повторно откройте приложение, чтобы проверить офлайн-доступ.

После этого стандартный режим, ответы, объяснения и прогресс доступны без сети. Для распознавания речи и проверки Groq нужен интернет.

Интернет понадобится для получения обновлений. В настройках нажмите **«Проверить обновление»**, а после загрузки новой версии — **«Применить обновление»**. Текущая работа сохраняется перед перезагрузкой.

Если данные сайта были очищены, для восстановления офлайн-доступа снова откройте приложение с интернетом. Резервную копию прогресса можно сохранить через **«Настройки → Экспорт JSON»**.
